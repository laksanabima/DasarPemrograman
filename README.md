## 1. Capaian Pembelajaran Lulusan (CPL)
RPS mengaitkan mata kuliah ini dengan tiga CPL:

1. CPL-01 — memahami dan menganalisis permasalahan computing serta konsep dasar dan peran sistem informasi dalam pengelolaan data dan pengambilan keputusan.
2. CPL-03 — memahami metodologi pengembangan sistem, alat pemodelan, dan analisis kebutuhan pengguna dalam membangun sistem informasi.
3. CPL-08 — bersikap proaktif dan inovatif dalam menerapkan teknologi informasi untuk menghasilkan solusi bagi masalah sosial, lingkungan, dan peningkatan kualitas hidup.kv
