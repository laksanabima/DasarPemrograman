# UJIAN TENGAH SEMESTER (UTS) — DASAR PEMROGRAMAN

Ujian Tengah Semester (UTS) ini menilai kemampuan mahasiswa dalam merancang algoritma dan mengimplementasikannya menjadi program Python yang terstruktur, mencakup materi minggu 1–7: algoritma, pseudocode, flowchart, struktur kontrol (sequence, selection, iteration), list, string, fungsi, serta pengujian program.

# Soal

Buatlah sebuah **aplikasi sederhana berbasis Python** yang menyelesaikan **satu permasalahan nyata** dengan **judul yang kamu tentukan sendiri**.

Tugas yang harus diselesaikan:

1. **Tentukan judul dan deskripsi aplikasi.**
   Jelaskan permasalahan yang diselesaikan dan siapa pengguna aplikasinya.

2. **Susun algoritma.**
   Tuliskan algoritma dalam bentuk **pseudocode** dan **flowchart**.

3. **Implementasikan dalam Python.**
   Program wajib memuat:
   - **Sequence** — urutan langkah yang berjalan berurutan.
   - **Selection** — percabangan (`if` / `elif` / `else`).
   - **Iteration** — perulangan (`for` / `while`).
   - **List** — pengolahan kumpulan data.
   - **Function** — fungsi dengan parameter dan/atau return value.

4. **Uji program.**
   Pastikan program berjalan tanpa error dan menghasilkan output yang benar untuk beberapa kasus uji.

5. **Susun laporan** sesuai format yang ditentukan.

6. **Buat video presentasi** yang menjelaskan kode program.

## Yang Dikumpulkan

1. **File program Python** — dengan format nama `nama_nim.py`.
2. **Laporan** — berisi algoritma, screenshot kode program Python yang jelas, dan link video presentasi.
3. **Video presentasi** — diunggah ke YouTube (tautan dicantumkan dalam laporan).
